3V_TD: RIFT DEFENSE - PC 실행

가장 간단한 실행:
- index.html 더블클릭
- 자동으로 local-test/index.html 단일 실행판을 엽니다.

개발 서버로 실행:
1. Node.js 22.x 설치
2. ZIP 압축 해제

5. http://localhost:4173 이 열리면 플레이

종료: CMD 창에서 Ctrl+C
