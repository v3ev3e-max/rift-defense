# Endless Compact Update

- 30-wave clear cap removed. Waves are generated indefinitely.
- Battle starts automatically; no wave-start button.
- 0.8 second automatic transition between waves.
- Elite pressure every 5 waves, alternating boss every 10 waves.
- Enemy/boss HP scales continuously for high waves.
- bestWave save validation no longer caps at 30.
- Battle UI simplified to field + compact status + Summon / Merge / Tactical controls.
- Operator detail, research, build and relic details moved into Tactical modal.
- PC layout includes left/right ad slots; mobile uses top/bottom ad slots.
- Mobile and desktop compact responsive overrides included.
