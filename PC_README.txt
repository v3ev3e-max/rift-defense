3V_TD / RIFT DEFENSE - PC VERSION

실행 방법
1. START_PC.bat 더블클릭
   또는
2. 3V_TD_PC.html을 Chrome / Edge에서 직접 열기

PC 조작
- 마우스 클릭: 요원 선택 / 버튼 조작
- 마우스 드래그: 배치된 요원 이동
- 요원 선택 후 빈 슬롯 클릭: 해당 슬롯으로 이동
- SPACE: 랜덤 소환
- M: 가능한 3중 합성
- ESC: 일시정지
- 1 / 2: 게임 속도 x1 / x2

PC 수정 사항
- PC 화면이 560px 모바일 폭으로 강제되던 CSS 오류 수정
- 761px 이상에서 전체 PC 전술 UI 사용
- 전장과 사이드바를 가로형으로 유지
- PC 전장 최소 폭 확보
- PC 하단에 키보드 단축키 안내 추가
- 모바일 레이아웃은 760px 이하에서만 적용

저장
- 브라우저 LocalStorage를 사용합니다.
- 브라우저 데이터 삭제 시 저장이 사라질 수 있으므로 설정의 저장 파일 내보내기를 권장합니다.
