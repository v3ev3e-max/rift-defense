# RIFT DEFENSE

현대 SF 도시의 균열을 막는 **Phaser 3 기반 랜덤 디펜스 RPG 플레이어블 알파**입니다. React나 백엔드 없이 실행되며 PC·모바일이 동일한 게임 코드와 저장 형식을 사용합니다.

**육성은 장기적인 강함을, 전략은 승률을, 운은 한 판의 반전을 만듭니다.**

## 실행

Node.js **22.12 이상** 권장(20.19 이상 지원).

```sh
npm install
npm run dev
```

터미널에 표시된 Local 주소(기본 `http://localhost:5173`)를 엽니다.

```sh
npm run build
npm run preview
```

`dist/`에 배포용 정적 파일과 오프라인 서비스 워커를 생성합니다. 환경 변수·DB·서버 설정은 필요하지 않습니다. Phaser는 전투 진입 때 지연 로딩됩니다. Phaser 엔진 청크에 대한 Vite 크기 경고는 빌드 실패가 아닙니다.

## 첫 플레이

1. 홈 → **덱 편성**. 처음에는 **추천 5인** 또는 전체 10인 덱을 사용합니다.
2. **출격 준비 → 전투 시작**.
3. **랜덤 소환**으로 요원을 배치합니다. 첫 튜토리얼의 3회는 같은 요원을 보장합니다.
4. 요원을 드래그하거나, 요원을 선택한 뒤 빈 슬롯을 눌러 이동합니다.
5. **웨이브 시작**을 눌러 자동 전투를 시작합니다.
6. 같은 영웅·같은 별 단계 3명이 모이면 **합성 가능!** 버튼으로 합성합니다.
7. 소환과 연구에 골드를 나눠 투자하고, 3웨이브마다 특성 하나를 선택합니다.
8. 10웨이브 중간 보스와 30웨이브 최종 보스를 저지합니다.
9. 결과 보상으로 요원 화면에서 영구 레벨을 올립니다.

합성 재료가 부족하면 **확정 소환**을 이용하세요. 무작정 덱을 넓히는 대신 덱의 종류를 줄이면 중복을 모으기 쉽습니다. 합성 한 기가 항상 정답은 아닙니다. 세 기가 담당하던 사거리·저지·시너지 수를 잃을 수 있습니다.

| 행동 | PC | 모바일 |

| 대체 이동 | 요원 선택 → 빈 슬롯 클릭 | 요원 선택 → 빈 슬롯 터치 |
| 대기석 배치 | 대기 요원 선택 → 슬롯 | 동일 |

| 일시정지 | ESC / 상단 버튼 | 상단 버튼 |

- 가로 화면을 기본으로 합니다. 세로 휴대폰에서는 회전 안내를 표시합니다.
- 전장 전체가 고정 카메라에 들어옵니다. 기본 화면 흔들림 OFF.
- safe-area와 `100dvh`, Phaser FIT 스케일, 터치 드래그 방지를 사용합니다.
- 낮은 화면 높이에서 우측 정보 패널과 전투 외 화면은 세로로 스크롤할 수 있습니다.
- 다른 탭으로 전환하면 전투가 자동으로 일시정지됩니다.
- 같은 Wi-Fi의 휴대폰에서 Vite 터미널의 **Network 주소**를 열어 개발 버전을 테스트할 수 있습니다. OS 방화벽에 의해 차단된다면 배포된 HTTPS 주소로 테스트하세요.
- 효과음은 첫 클릭/터치 이후 활성화됩니다. Web Audio를 사용할 수 없어도 게임은 동작합니다.

## 실제 구현된 시스템

### 전투

- 고정 맵 1개, 배치 슬롯 16개, 대기석 6개, 동시 적 상한 120.
- 소환 비용 10 GOLD / 확정 소환 25 GOLD. 확률 테이블은 `src/data/balance.ts`.
- 동일 영웅·단계 **3 → 1** 합성, 최대 5성. 3성·5성에서 관통·광역·도탄·드론 수 등이 진화.
- 10명 요원: 유리아·레이나·아린·카린·세라·노엘·루나·이브·미아·리제.
- 저지, 처치 자원, 관통, 치명타, 광역, 자율 드론, 회복, 감속, 아군 가속.
- 요원 HP, 교란 적의 공격/공속 저하, 전투불능 후 7초 자동 복귀.
- 직업별 연구: 최대 Lv.15, 레벨당 ATK +8% / ASPD +3.5% / 치명 확률 +1%p.
- 6개 빌드 각각 3단계: 화상 중첩·폭발, 전격 전이·감전, 출혈·치명 연계, 치명 추가탄, 폭발·파편·처치 폭발, 드론·자폭.
- 탄도 3기: 전체 공속 +10%, 위상 3기: 위상 공격력 +15%, 기계 3기: 드론 피해 +20%.
- 3웨이브마다 특성 3택, 5/15/20/25웨이브 유물 보상. 선택 중 전투 전체 정지.
- NORMAL / RARE / EPIC / LEGENDARY / JACKPOT. 특성의 나머지 두 선택칸은 각각 1%로 JACKPOT 판정. 첫 칸에는 성장 가능한 빌드 선택지를 보장합니다.
- 특성 새로고침 비용은 20, 40, 60… GOLD. 유물은 중복 획득하지 않습니다.
- 일반 적 6종과 보스 2종. 경계 파괴자는 체력 구간마다 가속, 영하의 군주는 주변 요원을 교란.
- 희귀 보급 이벤트, 웨이브 보상, 승패 및 MVP 피해량 집계.
- 30웨이브. 무적·추가 자원 없이 추천 덱을 조작하는 고정 시드 시뮬레이션은 약 11분 28초(게임 시간)에 완주했습니다. 실제 시간은 x2·특성 선택·일시정지에 따라 달라집니다.

### 계정

- 홈, 요원 기록, 덱 편성, 스테이지, 전투, 결과, 설정 화면.
- 전투 GOLD와 영구 CREDIT을 분리. 영구 레벨 최대 50, 레벨당 기본 ATK/HP +4%.
- `saveVersion: 1` 저장. 재화·덱·레벨·기록·설정·튜토리얼 자동 저장.
- 깨진 JSON·잘못된 영웅 ID·범위를 벗어난 숫자 복구/검증.
- 저장 파일 내보내기/가져오기. **PC와 모바일 간 서버 자동 동기화는 없습니다.** 같은 저장 파일로 수동 이동합니다.
- 저장소를 사용할 수 없는 환경에서는 안내와 파일 백업을 제공합니다.
- 돌파·스킬 레벨·장비·호감도는 데이터와 잠금 UI만 준비되어 있습니다.

### 성능 및 오프라인

- Phaser `requestAnimationFrame`, 1/60초 고정 시뮬레이션 스텝 + 누적 delta time. x1/x2 및 30/60/120Hz 논리 일관성을 테스트합니다.
- 적 120개, 렌더 스프라이트, 이펙트 100개 풀 재사용. 저사양 옵션은 표시 이펙트 25개로 제한합니다.
- 경로 끝 적 비활성화, 장면 종료 이벤트 정리, 전투 재입장 시 Phaser 인스턴스 재생성.
- 60FPS 목표이며 실제 90/120Hz와 저사양 모바일 성능은 기기에 따라 달라집니다. 실기기 측정은 후속 검증 대상입니다.
- PWA manifest, 192/512 아이콘, standalone, 빌드 해시별 오프라인 캐시.
- **온라인 최초 로드 및 서비스 워커 설치 완료 이후** 오프라인으로 새 전투를 시작할 수 있습니다. 개발 서버에서는 서비스 워커를 등록하지 않습니다.
- 진행 중 전투 자체는 저장하지 않습니다. 새로고침 시 홈으로 돌아오며 계정 데이터만 유지됩니다.

### 개발 디버그

`npm run dev` 전장 좌상단의 **DEV**를 펼치면 GOLD +1000 / 웨이브 +1 / 즉시 최종 보스 / 10명 영웅 생성 / 전체 5성 / 무적 / x5를 사용할 수 있습니다. 개발 버전에는 테스트용 `window.rift` 접근도 있습니다. `import.meta.env.DEV`로 감싸 프로덕션 빌드에서는 노출하지 않습니다.


## GitHub → Vercel 배포

1. 이 폴더를 GitHub 저장소에 push합니다. `node_modules`, `dist`, 저장 백업 파일은 올리지 않습니다.
2. Vercel에서 **Add New → Project → Import Git Repository**로 저장소를 선택합니다.
3. Framework Preset **Vite**, Build Command **`npm run build`**, Output Directory **`dist`**, Install Command **`npm install`**.
4. Node.js **22.x 또는 24.x**, 환경 변수 없음. **Deploy**.
5. 배포 URL에서 전투를 한 번 시작한 뒤 모바일 가로 화면과 오프라인 재접속을 확인합니다.

`vercel.json`이 기본 설정을 제공합니다. 화면 전환은 클라이언트 내부 상태를 사용하므로 별도 SPA URL rewrite가 필요 없습니다. 서비스 워커에는 `Cache-Control: no-cache`를 설정합니다. HTTPS 배포에서 PWA 설치가 가능합니다.

GitHub 저장소와 Vercel 프로젝트에 실제 업로드/배포하려면 사용자 계정의 연결과 대상 저장소가 필요합니다. 이 프로젝트에는 계정 토큰이나 배포 자격 증명을 포함하지 않습니다.

## 폴더 구조

```text
src/
  main.ts                 화면 전환, 입력, 계정 보상 연결
  style.css               PC / 모바일 UI
  game/
    GameConfig.ts         Phaser 설정 / 지연 로딩
    BattleScene.ts        고정 전장 렌더, 풀, 마우스/터치 입력
  entities/
    HeroUnit.ts           전투 요원, 합성 진화 집계
    Enemy.ts              재사용 적 상태
  systems/
    BattleModel.ts        순수 TypeScript 전투 상태 / 경제 / 진행
    CombatSystem.ts       공격, 상태이상, 드론, 저지, 보스 능력
    WaveSystem.ts         웨이브 생성 대기열
    SummonSystem.ts       가중치 소환
    MergeSystem.ts        합성 후보 탐색
    TraitSystem.ts        특성 선택지
    RelicSystem.ts        중복 없는 유물 선택
    SynergySystem.ts      배치 유닛 조합
    SaveSystem.ts         버전 저장 / 검증 / 영구 레벨
  data/                   영웅, 적, 웨이브, 빌드, 유물, 맵, 밸런스
  ui/                     공통 컴포넌트, 계정 화면, 전투 HUD
  utils/                  시드 난수, 안전한 Web Audio 효과음
public/assets/heroes/     자체 제작 픽셀 캐릭터 SVG / PNG
scripts/                  원본 에셋 생성, 빌드별 서비스 워커 생성
tests/                    순수 전투/저장 테스트
e2e/                      Playwright 브라우저 시나리오
```

`BattleModel`은 Phaser/DOM을 import하지 않아 렌더링 없이 테스트할 수 있습니다. 새 영웅은 `heroes.ts`의 기본 스탯·기존 진화 효과·에셋 키를 조합해 추가합니다. 완전히 새로운 능력 종류는 전투 효과 핸들러도 추가해야 합니다. 영웅의 `asset.url`과 `asset.key`, `asset.frame`으로 텍스처를 지정하고, `asset.atlas`에 JSON 경로를 넣으면 Phaser atlas 로더를 사용합니다. 슬롯의 `type`을 `melee` / `ranged`로 바꾸면 소환·이동·교환에서 해당 제한을 적용합니다. 초기 맵은 공용 슬롯입니다.

## 에셋과 라이선스

캐릭터, 전장, UI, 아이콘은 본 프로젝트에서 직접 생성했습니다. CDN 이미지/폰트나 라이선스 불명확한 게임 리소스는 사용하지 않았습니다. `npm run assets`로 동일 픽셀 캐릭터와 PWA 아이콘을 다시 생성할 수 있습니다. 자세한 내역은 [CREDITS.md](CREDITS.md)를 참고하세요.

## 아직 없는 기능 / 다음 우선순위

1. 실제 Android/iPhone에서 장시간 프레임·발열·터치 조작성 측정 및 UI 개선.
2. 여러 시드의 승률/경제 분석, 저지·지원 영웅 가치와 후반 난이도 조정.
3. 아틀라스 기반 캐릭터 애니메이션과 고유 일러스트, 추가 맵/스테이지.
4. 돌파·장비·스킬 레벨·호감도, 전투 중 이어하기와 자동 합성 옵션.

상점은 비활성입니다. 결제, 온라인 서버, PVP, 길드, 채팅, 광고를 구현하지 않았습니다.

## 세로 모드 / HTML 직접 테스트 (최신 변경)

배포하지 않고 `local-test/index.html`을 더블클릭해 실행하세요. 이 파일에는 Phaser, 게임 코드, CSS, 캐릭터 이미지가 모두 포함되어 있어 서버나 인터넷이 필요하지 않습니다. 루트의 `index.html`은 Vite 개발용 진입점이므로 직접 열기용 파일과 구분합니다.

- PC: 최대 560px 폭의 세로형 화면을 중앙에 표시합니다.
- 모바일: 회전 안내 없이 세로 화면에서 플레이합니다.
- 전장 아래에 요원 정보·연구·시너지, 맨 아래에 소환·합성 버튼을 배치했습니다.
- 현재 전장의 경로와 전투 밸런스는 유지했습니다.
- 짧은 화면에서는 전장/정보 영역을 스크롤할 수 있습니다.

코드 수정 후 직접 열기 파일을 갱신하려면:

```sh
npm run build:local
```
