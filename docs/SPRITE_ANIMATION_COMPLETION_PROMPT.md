# 전투 스프라이트 애니메이션 보완 제작 프롬프트

## 공통 제작 명세

Use case: stylized-concept
Asset type: 2D tower-defense combat sprite animation frames
Primary request: 기존 RIFT DEFENSE의 SD 캐릭터와 몬스터 디자인을 그대로 유지하면서, 실제 전투에서 빠진 동작을 개별 이미지 프레임으로 제작한다.
Input images: 각 영웅 또는 몬스터의 기존 정면·이동·스킬 이미지는 정체성 및 화풍 참조이자 편집 대상이다.
Scene/backdrop: 완전한 투명 배경. 바닥, 배경, UI, 글자 없음.
Style/medium: 현재 게임과 동일한 고해상도 애니풍 SD 게임 스프라이트. 선명한 외곽선, 채색 밀도와 광원 방향 유지.
Composition/framing: 모든 프레임에서 캐릭터 중심점, 발 위치, 머리 크기 및 카메라 각도를 고정한다. 384×384 정사각 캔버스, 사방 최소 40px 투명 안전 여백.
Constraints: 원본 얼굴·헤어·의상·무기·실루엣·속성을 변경하지 않는다. 프레임마다 새로운 장비나 장식을 추가하지 않는다. 모든 픽셀이 캔버스 안에 있어야 하며 머리카락, 검, 방패, 발사체, 광원이 가장자리에서 잘리지 않아야 한다. 프레임 간 색상과 선 굵기를 일치시킨다. 텍스트, 로고, 워터마크 없음.
Avoid: 캐릭터 재디자인, 전신 비율 변화, 프레임마다 얼굴 변화, 검·방패 손바꿈, 공용 캐릭터 이미지 복사, 불투명 배경, 그림자 사각형, 잘린 무기와 이펙트.

## 1. 영웅 대기 애니메이션

- 대상: 영웅 34명 전원.
- 기존 `frame_01~03`을 사용해 1→2→3→2 순서로 자연스럽게 반복한다.
- 호흡, 머리카락, 망토, 무기 끝의 미세한 움직임만 사용한다.
- 공격 또는 스킬 동작처럼 보이는 큰 자세 변화는 금지한다.
- 새 이미지가 필요한 캐릭터는 원본을 보존한 개별 편집으로만 생성한다.

## 2. 몬스터 근접 공격 애니메이션

- 각 지역·몬스터별로 6프레임을 제작한다.
- 프레임 구성: 기본 자세 → 예비 동작 → 무게중심 이동 → 타격 → 최대 후속 동작 → 기본 자세 복귀.
- 공격 방향은 진행 방향을 기준으로 하며 런타임 좌우 반전을 고려한다.
- 몬스터별 발톱, 주먹, 검, 창, 몸통 돌진 등 기존 실루엣에 맞는 공격법을 사용한다.
- 서로 다른 몬스터의 몸체 프레임을 공유하지 않는다.

## 3. 원거리 몬스터 발사 애니메이션

- 기존 발사 프레임이 없는 원거리 몬스터에 3프레임을 추가한다.
- 프레임 구성: 조준·충전 → 발사 순간 → 반동·복귀.
- 몸체 프레임과 발사체 이미지를 분리한다.

## 4. 네임드·보스 고유 스킬 애니메이션

- 네임드와 중간·최종 보스별로 6프레임을 제작한다.
- 프레임 구성: 경고 자세 → 에너지 집중 → 시전 준비 → 발동 → 최대 효과 → 후딜.
- 고유 속성과 패턴을 몸체 동작에서 명확히 읽을 수 있게 한다.
- `rage`, `frost`, `storm`, `void`, `disrupt` 한 장짜리 공용 효과만으로 시전을 대신하지 않는다.

## 5. 영웅 스킬 범위 효과 애니메이션

- 영웅 34명의 기존 고유 `skill.png`를 각각 4프레임으로 확장한다.
- 프레임 구성: 생성 → 확장 → 최대 발광 → 소멸.
- 캐릭터마다 기존 문양·색상·속성을 유지하며 다른 영웅의 프레임을 공유하지 않는다.
- 서포터는 공격 폭발 대신 회복, 보호막, 강화, 정화가 분명한 연출을 사용한다.

## 6. 런타임 및 검증 조건

- 대기·공격·발사·스킬·사망 상태가 겹치지 않도록 우선순위를 둔다.
- 대기 3프레임, 근접 공격 6프레임, 원거리 발사 3프레임, 보스 스킬 6프레임, 영웅 범위 스킬 4프레임을 실제 전투에서 재생한다.
- 모든 프레임에 동일한 40px 안전 여백을 적용한다.
- 파일 존재 여부뿐 아니라 실제 런타임 텍스처 선택을 테스트한다.
- 해시 검사로 캐릭터 간 복사, 평타·스킬 복사, 전체 프레임 정지 복사를 차단한다.
- PC 및 모바일에서 AUTO와 수동 스킬을 모두 재생 검증한다.
