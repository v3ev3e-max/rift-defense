# RIFT DEFENSE 영웅 제작 기준

새 영웅을 추가하거나 기존 영웅 이미지를 교체할 때 이 문서를 먼저 확인한다. 시각 기준 캐릭터는 `유리아(yuria)`다.

## 등급과 포지션

- 포지션은 탱커, 딜러, 저격수 중 하나로 등록한다.
- 각 등급에 각 포지션을 최소 2명 유지한다.
- 현재 최소 구성은 모두 충족한다. 다음 추가 순서는 선택지가 가장 적은 SR 탱커, SR 딜러, SR 저격수를 각각 3명까지 채우는 순서다.
- 새 영웅을 한 등급에 추가할 때 같은 등급의 포지션 수 차이가 2명을 넘지 않게 한다.
- `heroes.ts`, `combatRoles.ts`, `equipment.ts`, `campaignCombatBudget.ts`, `VisualRules.ts`, `WeaponSockets.ts` 등록을 한 작업으로 처리한다.

## 요원 메인 일러스트

- 기준 파일: `public/assets/illustrations/yuria.webp`
- 출력: WebP, 576×768, RGB 또는 RGBA.
- 얼굴이 화면 높이의 약 45~55%를 차지하는 얼굴 중심 상반신 구도다.
- 눈은 화면 높이 35~45% 지점에 둔다. 머리 위와 턱 아래가 잘리지 않아야 한다.
- 가슴 아래 전신, 무기 전체, 큰 방패가 얼굴보다 강조된 이미지는 사용하지 않는다.
- 배경은 캐릭터 속성색을 사용한 어두운 균열 분위기로 통일한다. 글자, 로고, 테두리, 워터마크는 넣지 않는다.
- UI에 적용하기 전에 5:4, 1:1 카드 크롭에서 얼굴과 머리 장식이 보이는지 확인한다.

## 얼굴 아이콘

- 출력: 512×512 PNG 원본과 필요 시 256×256 WebP.
- 메인 일러스트와 동일 인물·머리색·눈색·장식이어야 한다.
- 얼굴과 머리가 아이콘의 70~85%를 채우며 어깨 아래는 최소화한다.
- `src/ui/components.ts`의 확장자 연결과 실제 파일 확장자를 함께 확인한다.

## SD 전투 이미지와 애니메이션

- 모든 전투 프레임 캔버스는 160×160 투명 PNG다.
- 발 위치 기준선은 y=142±4, 캐릭터 중심은 x=80±5로 맞춘다.
- 대기 정면 1장, 측면 공격 8프레임, 위쪽 공격 6프레임, 쓰러짐 최대 3프레임을 준비한다.
- 각 프레임의 불투명 영역 높이 차이는 기준 포즈 대비 8% 이내로 유지한다. 공격 중 캐릭터 크기가 커지거나 작아지면 `poseSize`로 숨기기 전에 원본 프레임 크롭을 먼저 교정한다.
- 무기 끝 좌표는 `WeaponSockets.ts`에 측면 1·3·5프레임과 위쪽 1·3·5프레임 기준으로 기록한다.
- 기본 도형 임시 이펙트를 최종 에셋으로 사용하지 않는다. 평타 피격, 스킬, 탄환 또는 근접 궤적 이미지를 캐릭터 전투 방식에 맞게 제공한다.

## 적용 전 검사

1. 메인 일러스트와 얼굴 아이콘이 실제 UI 경로에서 로드되는지 확인한다.
2. 대기·측면 공격·위쪽 공격을 전환해 화면상 크기를 유리아와 비교한다.
3. 공격 방향, 무기 소켓, 탄환 시작점과 피격점을 확인한다.
4. 모바일 카드와 PC 요원 상세에서 얼굴이 잘리지 않는지 확인한다.
5. 영웅 데이터, 포지션, 장비군, 전투 예산, 자동 배치와 스킬 테스트를 실행한다.
