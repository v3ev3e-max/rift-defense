# 세계선 캠페인 구조

## 세계선 1 · 낙원 붕괴

기존 1~4지역, 40개 작전을 하나의 지상 원정으로 묶는다.

1. 바람 초원 — 바람에 열린 문
2. 푸른 해안 — 해안의 잔향
3. 고대 수림 — 기억하는 숲
4. 설원 성문 — 설원 성문의 결전

유리아, 레이나, 세라, 노엘, 아린이 최초 균열을 추적한다. 4지역 최종 작전을 완료하면 균열에서 다른 세계의 구조 신호가 발견되고 세계선 2가 개방된다.

## 세계선 2 · 폐쇄 연구구역

기존 5~8지역, 40개 작전을 별도 세계의 연구시설 원정으로 묶는다.

1. 중앙 연구동 — 응답 없는 연구동
2. 극저온 구획 — 얼어붙은 증거
3. 공허 관측소 — 관측자의 진실
4. 균열 핵 — 세계선의 심장

연구소는 균열을 봉쇄하던 시설이 아니라 여러 세계선을 인위적으로 겹치던 시설이다. 마지막 목표는 연쇄 붕괴가 시작되기 전에 균열 핵을 파괴하는 것이다.

## 진행 규칙

- 내부 저장 ID `1-1`~`8-10`은 기존 저장과 호환하기 위해 유지한다.
- 화면에는 `세계선-지역-작전` 형식으로 표시한다. 예: 기존 `5-1`은 `2-1-1`.
- 각 세계선은 지역 4개, 지역별 작전 10개로 구성된다.
- 세계선별 완료 수를 각각 40개 기준으로 표시한다.
- 세계선 2 출전은 세계선 1의 `4-10` 완료 후 해제된다.
- 로컬 테스트에서는 잠긴 세계선의 구성과 스토리를 미리 확인할 수 있지만 출전 순서는 유지된다.
- AUTO 다음은 같은 세계선 안에서만 연속 진행한다. 세계선 결말에서는 멈춰 다음 세계선의 스토리를 확인하게 한다.
- 캐릭터, 장비, 재화, 별 승급, 연구는 세계선 사이에서 공유한다.
- BGM 데이터와 재생 코드는 이번 변경 범위에서 제외했다.

## 세계선 선택 키아트

- `public/assets/campaign/worldlines/worldline-01.webp` — 낙원 붕괴, 960×320
- `public/assets/campaign/worldlines/worldline-02.webp` — 폐쇄 연구구역, 960×320

내장 ImageGen으로 제작했다. 첫 번째 프롬프트는 초원·해안·고대 수림·설원 성문과 청록색 균열을 한 장의 넓은 애니메이션 환경 콘셉트로 구성하고 인물·문자·UI를 제외하도록 지정했다. 두 번째 프롬프트는 폐쇄 연구시설·극저온 챔버·공허 관측창·균열 핵을 남색, 빙결 청록색, 절제된 보라색으로 구성하고 역시 인물·문자·UI를 제외하도록 지정했다.

## 전투 맵 에셋

8개 지역별 전용 원화를 내장 ImageGen으로 제작했다. 한 지역의 10개 작전은 같은 대표 배경을 유지하고 다음 지역에 진입할 때 배경을 전환한다.

- 원본 마스터: `public/assets/campaign/worldlines/area-masters/area-01-master.webp` ~ `area-08-master.webp` (1024×1024)
- 실제 사용 배경: `public/assets/campaign/map-1-1.webp` ~ `map-8-1.webp` (800×800)
- 지역당 10개 작전은 대표 배경 1장을 공유한다. 전투 중 배경이 자주 바뀌지 않고 지역 전환 시점에만 새로운 테마를 보여준다.
- 기존 작전별 변형 파일은 이후 세부 액트 확장용 원본으로 보관하며 현재 캠페인에서는 참조하지 않는다.
- 공통 생성 조건: 탑다운 정사각형 전장, 중앙 수평 전투 공간, 상하 배치 공간, 인물·적·UI·화살표·배치 패드·원화에 그려진 도로 제외.
- 세계선 1은 초원, 해안, 서양식 고대 수림, 설원 성문으로 구성했다.
- 세계선 2는 폐쇄 연구 외곽, 극저온 연구실, 공허 관측소, 균열 핵으로 구성했다.
- 일본풍 신사, 도리이, 탑, 등롱은 생성 금지 조건으로 지정했다.

## 두 갈래 전장 진행

- 1지역은 기본 배치와 단일 전방 저지를 익히도록 모두 단일 라인으로 유지한다.
- 2지역부터 두 갈래 전장을 도입하며, 후반 지역으로 갈수록 지역당 출현 횟수가 늘어난다.
- 두 갈래 전장은 `2-7`, `3-4`, `3-8`, `4-3`, `4-7`, `5-4`, `5-8`, `6-3`, `6-7`, `7-2`, `7-6`, `7-9`, `8-2`, `8-3`, `8-7`에 적용한다.
- 두 경로는 서로 다른 전방 배치 칸을 지나 하나의 코어 앞에서 합류한다. 적은 두 경로에 교대로 생성된다.
- 자동 배치는 탱커가 2명일 때 각 경로의 전방 칸에 한 명씩 배치하고, 저격수와 지원가는 후방에서 양쪽 경로를 지원한다.
- 지역 중간보스(`-5`)와 최종보스(`-10`)는 보스 점사와 패턴 확인에 집중하도록 단일 라인으로 유지한다.
