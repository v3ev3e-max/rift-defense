# 전투 완성도 전수 점검

## 34명 스킬

- 전체 34명이 1성 기준 30초 전투에서 최소 1회 이상 스킬을 사용한다.
- 수동 스킬과 AUTO 스킬은 같은 판정 및 이펙트 경로를 사용한다.
- 탱커 8명과 서포터 5명은 캐릭터별 4프레임 방어·지원 효과를 사용한다.
- 딜러와 저격수는 캐릭터별 고유 스킬 문양, 시전 효과와 3프레임 타격 효과를 사용한다.
- `public/assets/effects/<hero>/skill.png` 34개는 모두 존재하고 서로 다른 이미지 해시를 가진다.

## 기본 주인공 파티 난이도

조건은 유리아·레이나·세라·노엘·아린, 1성, 무장비, 연구 없음, AUTO 스킬 및 추천 자동 배치다.

| 지역 | 클리어 | 평균 코어 | 역할 |
|---|---:|---:|---|
| 1 | 10/10 | 100 | 배치·스킬 튜토리얼 |
| 2 | 10/10 | 100 | 고속 적과 첫 두 갈래 학습 |
| 3 | 10/10 | 100 | 혼합 적과 네임드 대응 |
| 4 | 10/10 | 100 | 중장 적과 보스 점사 |
| 5 | 10/10 | 99 | 기본 파티 최종 무장비 통과선 |
| 6 | 성장 필요 | - | 별 승급·장비 도입 |
| 7 | 성장 필요 | - | 속성·포지션 조합 강화 |
| 8 | 성장 필요 | - | 완성 편성 최종 시험 |

전체 80개 결과 원본은 `artifacts/five-unit-difficulty.json`에 저장한다.

## 두 갈래 전장

- 준비 화면에 A·B 라인과 권장 배치 안내를 표시한다.
- 전장 좌상단에 `2 LINE · A 위 / B 아래`를 유지한다.
- 탱커 2명은 A·B 전방을 각각 맡는다.
- 탱커 1명은 중앙 `FRONT C`에서 두 라인을 함께 저지할 수 있다.

## 네임드·보스 경고

- 네임드 고유 스킬 1.4초 전부터 적 본체에 주황색 분할 경고 링을 표시한다.
- 중간보스와 최종보스의 강공격 전에는 붉은 경고 링을 표시한다.
- 목표 지점 공격은 캐릭터 및 공격 효과보다 높은 레이어에 경고 이미지를 표시한다.

## 모바일 전투 UI

- 전투 상단 상태 표시를 고정한다.
- 다섯 스킬 카드는 한 줄 가로 목록으로 유지한다.
- 두 갈래 안내를 두 줄 이하로 압축한다.
- 부가 전투 정보는 접힌 상태로 높이를 제한한다.
- 360×740 및 412×915 Chromium 직접 실행에서 가로 넘침과 핵심 버튼 접근 문제가 없다.

## 다음 영웅·세계선 추가 기준

1. 신규 영웅은 전용 얼굴, 메인 일러스트, SD 기본·위쪽 공격·패배 프레임, 평타 투사체/타격, 스킬 시전/타격 이미지를 모두 갖춘 뒤 등록한다.
2. 30초 단독 감사에서 스킬이 최소 1회 발동하고 등급·포지션 예산 범위를 벗어나지 않아야 한다.
3. 신규 세계선은 대표 배경 1장당 10개 작전을 유지하며 중간보스와 최종보스에 별도 이미지와 경고 패턴을 제공한다.
4. 추가 지역은 직전 지역 성장 목표를 적용한 5인 파티로 80% 이상 일반 작전이 클리어되는지 모의한다.
5. PC와 360px 모바일 직접 실행 검증을 통과한 뒤 캠페인에 노출한다.
